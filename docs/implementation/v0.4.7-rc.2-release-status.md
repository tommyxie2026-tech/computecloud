## 已知限制

- 费用是 Claude 客户端估算值；单次 API 调用可能越过剩余额度，不声称供应商账单硬上限。
- Claude token、Codex token/cost 与混合 Provider 有限预算仍 fail closed。
- 真实 Codex/Claude、独立双主机、24h+ 长任务、生产升级/恢复、真实 NAT Relay、代表性缓存性能与签名 Mobile 仍未验收。
- 因此本版本只能发布为 prerelease，不更新 GHCR `latest`，不宣称生产认证。
