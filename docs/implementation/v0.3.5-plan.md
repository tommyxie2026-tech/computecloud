## 1. Goal

完成 v0.3.x Reliability Kernel 的公平排队与过载保护：

~~~text
Queued Task/Job
    ↓
retry_after / deadline eligibility
    ↓
effective priority = base + aging
    ↓
Project round-robin
    ↓
Job/group round-robin
    ↓
assign hard constraints
    ↓
Attempt
~~~

本版本不做 v0.5 的 Agent-aware score。

## 2. Milestones

### F1 — Scheduler limits

Jobs config 新增 scheduler_aging_seconds、max_queued_tasks、max_queued_tasks_per_project；默认分别为 300s、4096、1024，并有上限校验。

### F2 — Effective priority

- base priority 继续为 0..10；
- queue age 每经过一个 aging interval 提升 1；
- effective priority 最大 10；
- 不修改持久 Task priority；
- retry_after/deadline 先过滤，再做 aging。

### F3 — Hierarchical fair queue

- candidate group scan 上限 512；
- effective priority 从高到低；
- 同层 Project round-robin；
- Project 内 Job/group round-robin；
- 每个 group 每轮最多一次 assignment；
- Standalone Task 自身视为 group。

### F4 — Queue backpressure

- 新外部 Task/Job admission 检查 global/project queue；
- Job 按 initial Task 数做原子 admission；
- internal Reduce creation 不受 external admission 拒绝；
- idempotent replay 在 admission check 之前解析，因此 queue full 不破坏 replay。

### F5 — Blocker taxonomy

~~~text
JOB_CAPACITY_EXHAUSTED
PROJECT_CONCURRENCY_EXHAUSTED
CREDENTIAL_CONCURRENCY_EXHAUSTED
WORKER_CAPACITY_EXHAUSTED
NO_READY_WORKER
TEMPLATE_OR_CAPABILITY_MISMATCH
~~~

### F6 — CI

新增独立 fair-flow，覆盖 Project/group round-robin、priority aging、retry_after 不被 aging 绕过、queue backpressure、saturated queue 下 idempotent replay、specific capacity blockers、旧 Job fairness regression。

package 依赖七个 Gate：

~~~

## 3. Release invariants

~~~text
equal-priority runnable Projects make bounded progress
aging eventually raises old work but never bypasses retry_after/deadline
external queue admission is bounded
accepted idempotent replay is never rejected by later saturation
specific capacity blocker is observable
running Attempts are never preempted
~~~

## 4. Compatibility

- 无新的 Server/Worker schema；
- JobSpec 仅增加向后兼容的 `limits.priority` 可选字段（0..10，省略等价 0）；Task protobuf 不变；
- priority 范围保持 0..10；
- 原 per-job/project/credential/worker capacity 约束继续有效；
- Server restart 允许丢失公平 cursor，但不能丢失 durable queue state。
