# v0.4.3 EnvironmentCapability Foundation 实施计划

- 日期：2026-09-28
- Issue：[#31](https://github.com/tommyxie2026-tech/computecloud/issues/31)
- 分支：`feat/v0.4.3-environment-capability`
- ADR：[ADR-015](../adr/0015-environment-capability.md)

## Goal

把 Environment 从 Runtime capability 附属字符串提升为独立、可验证、可授权的 contract，同时保持 Scheduler generic、Job/Attempt 语义不变。

## Milestones

### E1 — Registry
- `internal/environment` Descriptor / Registry；
- builtin `process`；
- descriptor validation。

### E2 — Worker advertisement
- Worker 广告 `registered ∩ Runtime-compatible`；
- 未注册 Environment 不广告。

### E3 — Job contract
- Execution 可选 `environment`；
- 省略默认 `process`；
- 冻结为 `environment:<name>` required capability。

### E4 — Policy gate
- `allowed_environments`；
- Policy 进入 TemplateDigest；
- Workspace prepare / Runtime Prepare/Start 前 fail closed。

### E5 — CI
- 新增 `environment-contract-flow`；
- package 依赖既有十个 Gate + environment-contract-flow。
