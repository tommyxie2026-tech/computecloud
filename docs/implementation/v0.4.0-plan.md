## 1. Goal

进入 v0.4.x Runtime / Tool / Environment 生态阶段，先解决“新增 Runtime 是否需要修改 Worker/Scheduler 核心代码”这个扩展性问题。

目标结构：

~~~text
Worker
  ↓
Runtime Registry
  ↓
Provider Contract
  ├── Codex
  ├── Claude
  └── Future Runtime
~~~

Scheduler 继续只理解：

~~~text
profile
model
credential
repository
policy
verifier
required capabilities
~~~

而不理解具体 Runtime 实现。

## 2. Milestones

### R1 — Provider contract

增加：

- Provider registry；
- Profile；
- Probe；
- Args；
- Stream Parser；
- CapabilitySet；
- Gateway support declaration。

### R2 — Built-in Providers

把既有：

~~~text
codex_exec
claude_print
~~~

迁移为注册式 Provider。

旧 `adapter.Args` 保留 compatibility wrapper。

### R3 — Worker decoupling

Worker probe：

- 从 Registry 查找 Provider；
- Provider 自己执行 probe；
- Provider 产生 capability advertisement。

Worker execute：

- Provider 产生 Args；
- Provider 产生 Parser；
- Gateway eligibility 使用 Provider declaration。

核心 Worker 文件不再包含 `codex_exec / claude_print` profile 判断。

### R4 — Capability namespaces

统一新能力命名：

~~~text
runtime:*
tool:*
environment:*
~~~

v0.4.0 继续同时广告 legacy capability，保证旧客户端和 JobSpec 不破坏。

### R5 — Scheduler compatibility

现有 Scheduler 不新增 Runtime-specific code。

测试覆盖：

- namespaced runtime capability；
- namespaced tool capability；
- namespaced environment capability；
- legacy capability；
- 缺失 capability fail closed。

### R6 — Contract CI

新增独立 `runtime-contract-flow`：

- built-in Provider contract；
- test Provider 注册；
- deterministic capabilities；
- namespace coverage；
- legacy compatibility；
- Gateway Provider ownership；
- Scheduler namespaced matching；
- Worker/Server core profile-hardcoding static scan。

package 必须依赖：

~~~text
verify
task-flow
retry-flow
artifact-flow
workspace-flow
long-run-flow
fair-flow
runtime-contract-flow
~~~

## 3. Release invariants

~~~text
Runtime profile dispatch is registry-driven
unknown Runtime is rejected before execution
Provider capability declaration is deterministic
Runtime/Tool/Environment namespaces do not collide
Codex/Claude existing Jobs remain compatible
adding a test Runtime requires no Scheduler code change
Gateway eligibility is declared by Provider
~~~

## 4. Compatibility

- 无 Server schema migration；
- 无 Worker schema migration；
- protobuf wire contract 不变化；
- Codex/Claude profile 名称不变化；
- legacy capabilities 继续可用；
- Makefile 开发版本进入 0.4.0。

fixture contract CI 不证明：

- 真实 Codex/Claude 新版本兼容性；
- 第三方真实 Agent Provider；
- API-backed Runtime 网络故障；
- managed Agent API；
- Environment isolation。
