`internal/worker/workspace_lifecycle_test.go` 中旧 `TestWorkspaceGenerationIsolationAndOwnership`
fixture 只提供 repository，没有 Runtime 配置；执行 `ci_prepared_workspace_recovery.py` 得到：

