# v0.4.2 ToolCapability Foundation 实施计划

- 日期：2026-09-28
- 目标版本：v0.4.2
- 基线：v0.4.1 Transport-neutral Runtime Execution
- Issue：[#29](https://github.com/tommyxie2026-tech/computecloud/issues/29)
- 分支：`feat/v0.4.2-tool-capability`
- ADR：[ADR-014](../adr/0014-tool-capability.md)

## Goal

把 Tool 从 Runtime Provider 的附属 capability 字符串提升为独立、可验证、可授权的 capability contract，但不在本版本引入通用 Tool execution framework。

## Milestones

### T1 — Independent Tool Registry

新增 `internal/tool`：

- Descriptor；
- version；
- side_effect；
- registration / lookup；
- deterministic names；
- built-in `artifact_inputs_v1 / job_io_v1`。

### T2 — Worker capability intersection

Worker probe 改为：

~~~text
provider compatible tools
        ∩
registered tools
        ↓
tool:* advertisement
~~~

未注册 Tool 不进入 WorkerHello。

### T3 — Job Tool requirements

Job Execution 增加可选 `tools[]`，最多 16 个、唯一、受限命名。

冻结后映射为：

~~~text
tool:<name>
~~~

并进入现有 Task `required_capabilities`。

### T4 — Policy gate

Worker Policy 增加 `allowed_tools`。

Worker 在 Workspace/Runtime execution 前验证：

- Tool 已注册；
- Runtime compatible；
- Policy allowed。

拒绝发生在 Provider Prepare/Start 前。

### T5 — Standalone Task compatibility

Standalone Task 保留 legacy capability，同时允许受限 namespaced capability：

~~~text
runtime:*
tool:*
environment:*
~~~

Scheduler 核心保持 generic capability matching。

### T6 — Template fencing

非空 `allowed_tools` 进入既有 Policy serialization，因此影响 TemplateDigest；Policy 改动继续触发 template mismatch fencing。

### T7 — CI

新增独立 `tool-contract-flow`，覆盖：

- Tool registry；
- installed/compatible intersection；
- Job -> Task namespaced requirement；
- Policy digest；
- Policy denial before Runtime Start；
- unregistered Tool filtering；
- Scheduler no Tool-specific hardcoding。

Package 必须依赖既有九个 Gate + `tool-contract-flow`。

## Release invariants

~~~text
0 unregistered Tool advertisements
0 Tool-policy bypass before Runtime Start
0 mutable Job Tool requirements after acceptance
0 Tool-specific Scheduler branches
legacy Jobs remain compatible
Runtime/Attempt/Artifact/Workspace invariants remain unchanged
~~~

## Non-goals

真实外部 Tool invocation、审批流、EnvironmentProvider、Prepared Workspace、v0.5 scoring、RBAC/HA 均不属于 v0.4.2。
