## 第一版边界

- 实现真实 CLI 的调用和协议解析，自动测试使用可控的协议兼容 fixture；不会将 fixture 结果称为真实模型验收。
- 支持多进程/多节点协议，当前环境可验证两 Worker 进程；两台独立机器和用户实际模型账号另列环境验收。
- 不自动重跑状态不明的执行，不开启跨节点会话迁移；原生 resume、执行中输入和审批仅在能力经过验证后开放，未支持时明确拒绝。
- 默认受信 Linux 进程模式；不把进程组当作不可信多租户沙箱。
- 保留设计文档作为目标，以本计划和运行指南明确已实现子集及后续能力。
