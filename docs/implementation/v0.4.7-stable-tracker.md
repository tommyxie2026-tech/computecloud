# v0.4.7 stable release tracker

This tracker is the live execution ledger for the stable release plan in
[`docs/superpowers/plans/2026-10-09-v0.4.7-stable-release.md`](../superpowers/plans/2026-10-09-v0.4.7-stable-release.md).
The product remains an Agent-aware Distributed Job Execution Platform / Agent
Job Executor. Stable release claims never extend to an AI Execution OS, generic
Workflow Engine, LLM Gateway, Model Serving Platform, or GPU Cloud.

Status values are `PLANNED`, `IN_PROGRESS`, `BLOCKED_ENV`, `FAILED`, `DONE`,
`DEFERRED`, and `RELEASED`. A fixture or CI result cannot change a real-host row
to `DONE`.

## Current blockers

- GitHub issue #1/#9 production baseline remains open because real hosts,
  authorized Runtime accounts and a 24h+ execution window are not available in
  the current CI-only environment.
- The repository can complete RLY-04/RLY-05 and all fail-closed evidence
  validators before the environment is available.
- Mobile pairing/push/signing belongs to v0.5.x and is not a v0.4.7 Gate.
- Automatic Re-plan, broader token/cost budgets and production-default Relay are
  not silently enabled by this plan.

## Update rule

Every status change records a PR/commit, exact command or real report path, and
result. Failures stay visible until replaced by new evidence; they are not
deleted. `release/v0.4.7.json` must not be added until REL-GATE is `DONE`.
