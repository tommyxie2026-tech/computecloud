# v0.4.3 EnvironmentCapability 运行与扩展

- 目标版本：v0.4.3
- ADR：[ADR-015](../adr/0015-environment-capability.md)

## 1. 当前内建 Environment

~~~text
process
  isolation_class = process
  filesystem_mode = workspace
  network_mode = host
  legacy_default = true
~~~

## 2. JobSpec

Execution 可选：

~~~json
{
  "environment": "process"
}
~~~

省略时 Server 同样冻结为 `environment:process`。

## 3. Worker Policy

~~~yaml
policies:
  batch:
    allowed_environments:
      - process
~~~

未配置时只允许 legacy-default Environment。

## 4. 调度与执行

调度仍只看 `required_capabilities`。Worker 在开始 Workspace prepare 之前校验：Environment 已注册、Runtime 声明兼容、Policy 允许。

## 5. 扩展规则

新增 Environment capability 时必须同时提供可信的执行实现后再广告该能力；仅注册名字不应被视为 Sandbox 实现。后续 container/VM/external sandbox 会在独立 EnvironmentProvider 版本中完成。

## 6. Compatibility / rollback

旧 Job 未声明 environment 时默认 process。v0.4.3 不增加 DB schema 或 protobuf breaking change。回退到旧 Server 前应停止提交显式 `environment` 的新 JobSpec。

## 7. Boundary

本版本只稳定 capability/policy contract，不提供 container/VM/sandbox lifecycle、网络隔离、snapshot 或 Prepared Workspace。
