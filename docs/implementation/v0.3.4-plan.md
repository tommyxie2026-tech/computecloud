- ADR：[ADR-010](../adr/0010-long-running-job-reliability.md)

## 1. Goal

使数分钟到数天的 Agent Job 拥有明确的 liveness、deadline、cancel cleanup 和事件保留语义，同时不引入 Session/Workflow/HA。

~~~text
Runtime output ───────┐
                      │ 不作为 liveness
Worker Renew ─────────┼──> Attempt last_renewed / lease_until
                      │
Explicit deadline ────┼──> Server execution authority
Cancel / timeout ─────┘
        ↓
TERM -> KILL -> cleanup proof
~~~

## 2. Milestones

### L1 — Server schema v7

- `attempts.last_renewed`；
- `tasks.event_floor_seq`；
- `event_dedup`；
- v6 -> v7 migration；
- migration/integrity tests。

### L2 — Lease liveness

- Assignment creation初始化 `last_renewed`；
- 每次合法 Renew 同时推进 `last_renewed / lease_until`；
- API task projection 暴露两个时间；
- 无 Runtime output 不触发 hung 判定。

### L3 — Explicit deadline extension

- HTTP `POST /v1/jobs/{id}/deadline`；
- MCP `extend_job_deadline`；
- `jobs:extend` scope；
- operation_id idempotency；
- monotonic extension；
- per-operation / total-runtime policy；
- 同步未终态 child Task deadline；
- 不改变 Retry/generation。

### L4 — Mutable deadline execution

Worker 不使用 Assignment 中冻结的 deadline 作为本地 process deadline。Server 通过 deadline controller + renewable lease + stop command 保持执行权威。

断开 Server 后，Worker 仍会在 lease 到期时停止。

### L5 — Cancellation escalation evidence

- process group SIGTERM；
- grace 到期 SIGKILL；
- `TermSent / KillSent / Cleanup`；
- `attempt.stop_escalation`；
- timeout/cancel 不得发布 success；
- cleanup unknown 继续进入 RECONCILING/QUARANTINED 路径。

### L6 — Bounded Task events

- `max_task_events`，默认 2000；
- bounded background compaction；
- 保留 worker_seq/hash dedup；
- `EVENT_CURSOR_COMPACTED floor=N`；
- Job events 本版本不压缩。

### L7 — CI

新增 `long-run-flow`，覆盖：

- no-output lease renewal；
- explicit deadline extension；
- deadline idempotency；
- timeout cannot succeed；
- event compaction + cursor floor；
- replay dedup metadata；
- TERM -> KILL escalation；
- schema v7。

package 必须依赖：

~~~text
verify
task-flow
retry-flow
artifact-flow
workspace-flow
long-run-flow
~~~

## 4. Production boundary

fixture CI 只证明控制语义。以下仍属于 Production Baseline #1：

- 真实 Codex / Claude 24h+；
- ≥2 独立 Linux host；
- 真实网络 partition/reconnect；
- 实际磁盘/负载条件；
- 真实 Runtime 长时间容量与资源曲线。
