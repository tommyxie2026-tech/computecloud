## 发布后验收边界

真实公网入口/WAF 与源站不可绕过、Worker A/B mTLS 证书轮换/撤销、OCI/egress 负向隔离、供应商硬账单上限及真实双机升级/恢复仍须在目标环境独立验收。CI 和模拟结果不证明任意不可信公网租户的生产安全认证；具体步骤见[部署与回退指南](../deployment/production-v0.4.8.md)和[公网访问安全验收手册](../validation/public-access-security-acceptance.md)。

项目定位保持为 Agent-aware Distributed Job Execution Platform / Agent Job Executor，不扩展为 AI Execution OS、通用 Workflow Engine、LLM Gateway、Model Serving Platform 或 GPU Cloud。
