## 发布后验收边界

双 Worker 跨主机注册与分别成功执行任务，已在受控目标部署中验证；该证据不覆盖负载均衡公平性、mTLS 证书轮换/撤销、OCI/egress 负向隔离或双机升级/恢复。真实公网入口/WAF 与源站不可绕过、供应商硬账单上限及上述安全与恢复项目仍须独立验收。CI 和模拟结果不证明任意不可信公网租户的生产安全认证；具体步骤见[部署与回退指南](../deployment/production-v0.4.8.md)和[公网访问安全验收手册](../validation/public-access-security-acceptance.md)。

项目定位保持为 Agent-aware Distributed Job Execution Platform / Agent Job Executor，不扩展为 AI Execution OS、通用 Workflow Engine、LLM Gateway、Model Serving Platform 或 GPU Cloud。
