# v0.4.4 EnvironmentProvider Execution 实施计划

- 日期：2026-09-28
- Issue：[#33](https://github.com/tommyxie2026-tech/computecloud/issues/33)
- 分支：`feat/v0.4.4-environment-execution`
- ADR：[ADR-016](../adr/0016-environment-provider-execution.md)

## Goal

把 v0.4.3 的 Environment capability/policy contract 推进为可恢复的 execution Provider，使 Worker 能在不增加 Environment 名称分支的前提下编排 process、未来 container/VM/external sandbox。

## Milestones

### E1 — Provider contract

- `Descriptor / Prepare / Activate / Inspect / Release`；
- `EnvironmentRef`；
- `EnvironmentState`；
- `CleanupState`；
- builtin process Provider。

### E2 — Worker schema v5

runs 增加 environment provider/ref/state/cleanup，并保证 legacy v4 数据升级后为空值、行为不变。

### E3 — Execution integration

顺序固定：

~~~text
Policy gate
  ↓
Workspace prepare
  ↓
Environment Prepare
  ↓
persist EnvironmentRef
  ↓
Environment Activate
  ↓
persist ACTIVE
  ↓
Runtime Prepare
  ↓
Runtime Start
  ↓
Runtime cleanup
  ↓
Environment Release
  ↓
Attempt completion
~~~

Runtime 只能使用 Environment Provider 返回的 CWD / Env。

### E4 — Restart recovery

Worker restart 读取 durable EnvironmentRef，通过 Inspect/Release 获得 cleanup proof。UNKNOWN 或 release failure 继续 fail closed，不允许 Retry Safety 把旧 generation 视为清理完成。

### E5 — Fixture Provider

增加非 process fixture Environment，验证：

- Provider 可改变 Runtime Env/CWD context；
- Runtime 不需要知道 Environment 名称；
- cleanup confirmed 成功；
- cleanup unknown -> completion failed + Workspace QUARANTINED；
- restart recovery 依赖 Inspect/Release。

### E6 — CI

新增独立 `environment-execution-flow`，并把 package Gate 扩展为：

~~~text
verify
task-flow
retry-flow
artifact-flow
workspace-flow
long-run-flow
fair-flow
runtime-contract-flow
runtime-execution-flow
tool-contract-flow
environment-contract-flow
environment-execution-flow
~~~

## Release invariants

~~~text
Environment execution is Provider-owned
EnvironmentRef durable before Runtime Start
Runtime sees only Environment-prepared CWD/Env
cleanup = runtime cleanup AND environment cleanup
UNKNOWN Environment fails closed
restart cannot silently reuse an old Environment
descriptor-only Environment is never advertised
Scheduler remains generic
~~~

## Non-goals

生产 container/VM、external sandbox、NetworkPolicy enforcement、snapshot/checkpoint、Prepared Workspace、cross-worker migration、v0.5 scoring、RBAC、HA 均不属于本版本。
