## 2. Tool contract 证据

- `internal/tool` Registry 与 Runtime Registry 独立；
- Worker 只广告 `registered ∩ runtime-compatible` 的 Tool；
- Job `tools[]` 冻结为 `tool:<name>` Task requirement；
- `allowed_tools` 进入 Worker Policy 和 TemplateDigest；
- Tool Policy denial 发生在 Runtime Prepare/Start 之前；
- standalone Task 允许受限 `runtime:* / tool:* / environment:*` namespace；
- Scheduler 仍只处理 generic `required_capabilities`，没有 Tool 名称特例；
- 未注册 Tool 不进入 WorkerHello；
- Tool side-effect 只做描述，不隐式改变 Replay Safety。

## 3. Compatibility

- 旧 Job 未声明 `tools[]` 时行为保持兼容；
- legacy event_stream/cancel 与平台 Tool compatibility window 保留；
- v0.4.2 不引入 DB schema migration 或 protobuf breaking change；
- 回退到旧 Server 前应停止提交包含 `tools[]` 的新 JobSpec。
