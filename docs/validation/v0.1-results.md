## 二进制烟测

脚本使用生成的临时配置、独立进程、真实 Git 仓库和 computecloud CLI，不直接调用内部 Go 方法。一次完整运行包含：

1. 四个正常任务，Codex/Claude 协议各两个，两个 Worker 都参与执行；验证重复提交返回同 ID。
2. watch 回放连续事件；下载结果包，校验 SHA-256 与三个成员文件。
3. 运行长任务并取消，等待 CANCELED，检查后代进程已消失或为僵尸而非仍执行。
4. SIGKILL Worker 后重新启动，检查遗留子进程停止，Task 为 FAILED，没有自动再次执行任务。
5. SIGKILL server，等待超过 4 秒测试租约；检查 Worker 本地停止后代。重启 server，检查任务恢复为 WORKER_LOST，先前成功任务仍保留。
6. 排空并停止服务，使用 backup 命令；还原后 integrity_check=ok，7 个任务记录和产物哈希一致。

脚本输出的四组 PASS 对应生命周期、Worker 恢复、server/租约恢复和备份恢复。关键故障场景本轮为单次注入，未完成完整 PoC 要求的多轮统计。没有据此估计生产故障率。
