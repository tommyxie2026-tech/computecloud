## 2. 与计划验收的关系

V01–V17、V22 的核心场景已有本地自动覆盖；V18–V21 已覆盖模拟模型协议、权限与用量。本机 fixture 容量矩阵已经通过。以下仍不标为通过：真实 Codex MCP/Responses 兼容，真实 Claude 输出稳定性，独立主机间 TLS/网络故障，真实模型容量与供应商账单对照。

屏障重启测试验证持久事务前后重开；实际 SIGKILL 烟测覆盖执行中 Server/Worker 崩溃。没有在 SQLite 每条指令之间逐点杀进程，也未穷举所有文件系统 ENOSPC、网络设备和 Git rename/submodule 组合。SQLite 页容量耗尽是存储失败注入，不能替代所有磁盘故障。

## 3. 交付边界

这是可构建和运行的 v0.2 首版实现。Job 核心可按运行指南接入受信节点；G1 默认关闭，固定真实 Codex 版本、上游与模型完成兼容验收后再启用。

尚未实现：自动重试、多代 Attempt、任意 DAG、自动分片 Planner、共享 Session、交互审批、容器隔离、控制面 HA、历史 GC、严格费用预算。任务与模型请求均不会在不确定执行后自动重放。执行结果和进程清理状态必须分别核实。
